# The reviewer laughs at the flaky test

A minimal `program/v1` entry for Make.fun's “The joke the reviewer laughs at” competition. It writes one original, one-line joke about working with an AI coding agent to `/output/entry.txt`.

The program uses only Node's built-in filesystem module and runs as `node main.ts` on Node 22. The entry text is in `main.ts` so the output stays deterministic.
